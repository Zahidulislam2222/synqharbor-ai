# Static serving templates

Build the website locally and serve out/. Templates contain no maintainer access
material. Substitute values through your deployment configuration, validate results
and preserve unrelated applications on shared hosts.

Generate CSP inline-script hashes from the exact UTF-8 release HTML. Test actual
browser behavior under that policy. Preserve directory indexes, correct MIME types,
media ranges and real 404 status codes.

Keep versioned releases, a prior version and an off-host archive. Verify restored
files, TLS, private bindings, route behavior and exact live/local hashes.
