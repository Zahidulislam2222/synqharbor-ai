# Acceptable use

Last reviewed: 2026-10-16.

Responsible use protects collaborators, operators and the systems connected to their work.

## Permitted use

Explore the public information and interface, read the code and documentation, and report issues through the stated channels.

- Follow the source license
- Use only data you are entitled to share
- Stay within authorized security research scope

## Prohibited activity

Do not attempt credential theft, unauthorized access, malware distribution, harassment, deceptive impersonation or disruption of other services.

- No scanning unrelated infrastructure
- No bulk abuse of support channels
- No unlawful or rights-infringing content

## Future agent execution

The platform roadmap requires least-privilege grants, bounded execution and human authorization for consequential external actions.

- A prompt cannot override permissions
- Connector grants can be revoked
- Execution policies accompany each supported adapter

Contact: [project maintainer](https://github.com/Zahidulislam2222). Arrange a private channel before sharing personal data; never put credentials or confidential data into public issues.
