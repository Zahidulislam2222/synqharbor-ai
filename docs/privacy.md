# Privacy

Last reviewed: 2026-10-16.

This policy describes the current website. A future authenticated service will publish an updated processing schedule before accepting account or client-workspace data.

## Current website information

The website does not provide account registration, analytics advertising or an intake form. Workspace edits exist in browser-tab memory and disappear on reload.

- Static resources are requested from hosting and network providers
- Network/security logs may contain IP, URL, timestamp and browser information
- No workspace content is transmitted by the current interface

## Hosting and third-party links

The current deployment uses an existing Contabo server and Cloudflare delivery/security services. Their independent network processing is covered by their own policies. Following a GitHub link enters GitHub’s service.

- No advertising trackers are installed
- No inference provider receives workspace content
- The operator controls server access and log rotation
- Server logs use capacity-based rotation; a fixed age-based retention limit is not currently verified

## Rights, retention and future processing

Contact the maintainer through the contact page for a privacy concern. Retention, rights handling, processing roles and applicable law must be specified for each future hosted customer deployment.

- Self-host operators control their deployment data
- Do not enter sensitive client content in public feedback
- No jurisdiction-specific certification is claimed
